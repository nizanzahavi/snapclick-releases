# SnapClick

A free, offline screenshot and annotation app for Windows.

## Download

Get the latest from the [Releases](../../releases/latest) page:

- **SnapClick-Setup.exe**: the installer. Run it, follow the steps, and SnapClick is installed for your user (no administrator rights needed) with a Start menu entry and an uninstaller.
- **SnapClick.exe**: the app on its own, a single file. Download it, run it, and it sits in the system tray. There is nothing to install.

Windows 10 or 11 (64-bit). No .NET or other software is needed.

SnapClick checks this page for new versions and offers to update itself.

The source code is not published here; this repository only hosts the downloads.
